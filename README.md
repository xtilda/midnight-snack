# Midnight Snack

A browser maze game: collect five snacks and return to the blue door while avoiding the milk and cheese. You have three lives. Hot Sauce lets you chase enemies for seven seconds; collecting snacks in quick succession earns bonus points.

## Run

From the project folder:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. 

Move with **arrow keys / WASD** or the mobile direction buttons. Press **P / Esc** to pause; use **Restart** for a new run.
